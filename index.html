🚀 Automated Deployment Pipeline

This static website demonstrates a CI/CD workflow using GitHub Actions and Amazon S3. Every push to the repository triggers an automated pipeline that performs the following steps:

  • ✔️ Checkout code from GitHub repository
  • ✔️ Configure AWS credentials securely
  • ✔️ Sync static files to Amazon S3 bucket
  • ✔️ Serve content via S3 static website hosting

This setup highlights cloud automation, infrastructure as code, and continuous delivery practices. A simple but powerful demonstration of modern DevOps workflows.
